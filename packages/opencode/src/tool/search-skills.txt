Search for skills using keyword-based BM25 search.

Enter a natural language query to find relevant skills. The search engine uses
BM25 algorithm with pre-built inverted index for fast, accurate results.

Results include skill name, description, tags, tier, and relevance score.
Use load_skill to load the full content of a skill you find.

Usage:
- search_skills({ query: "git worktree branch management" })
- search_skills({ query: "code review", limit: 5 })
- search_skills({ query: "testing", tier: "CORE" })
